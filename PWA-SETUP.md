### Security Notes

**Supabase API NOT Cached**
- All Supabase requests bypass service worker
- Face recognition uploads always fresh
- PIN verification always fresh
- QR check-in always fresh

**Cache Strategy**
- Static assets: Precached (HTML, CSS, JS, icons)
- Google Fonts: CacheFirst (1 year)
- Face-API models: CacheFirst (30 days)
- Supabase: Network-only (no cache)
