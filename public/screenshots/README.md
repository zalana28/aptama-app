# Screenshots

Untuk melengkapi PWA manifest, tambahkan 3 screenshot mobile:

1. `home.png` - Screenshot halaman Beranda (390x844 atau 412x915)
2. `scan-qr.png` - Screenshot halaman Scan QR (390x844 atau 412x915)
3. `rekap.png` - Screenshot halaman Rekap (390x844 atau 412x915)

Screenshot bisa diambil dari device mobile atau browser DevTools mobile mode.

Untuk sementara, PWA akan tetap berfungsi tanpa screenshot, tapi PWABuilder score akan lebih rendah.
